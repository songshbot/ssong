## 3. Hospital (`SAVAC_hospital.Rmd`)

### 사이트별 구조 (중요)
- **MLW**: 질환별 form. RHD는 `rhd` + `rhd_followup` form, 이벤트 `rhd_arm_1`. MLW가 기준(reference).
- **PGI**: MLW와 거의 같음. 차이:
  - `rh_adm_dt` 없음 → `rh_enrol_from`(1 OPD / 2 IPD)에 따라 `rh_adm_opd_dt` / `rh_adm_ipd_dt`
  - PGI에만: `rh_enrol_from`, `rh_opd_visit_dt`, `rh_enrol_opd`, `rh_visit_reason`, `rh_visit_reason_x`
  - `rhf_disch_dt_na` 코드 3(OPD 등록), `rhf_rtn` 코드 3(waiver) 추가 → 표에 `[code 3]`으로 표시
- **MRCG**: 공통 CRF 모듈 구조로 완전히 다름(cda_ 인구학, phr_ 병력, cin_ 검사, rhd_ RHD CRF 15개,
  adm_ 입원/결과, fwu_ 추적). RHD 대상은 `rhd_ppc_adm___1~10` 중 하나라도 1인 레코드.
  나이 `cda_dob_cal_yrs`(DOB→입원일 계산), 동의일 `cda_dt_con`.

### 섹션 구성
1-4. 로드, RHD 데이터셋(MLW/PGI: `rhd_arm_1` + `rh*` 변수만 / MRCG: rhd_ppc_adm 조건, 전체 변수), 중복 확인
5. 개수 한 줄씩 확인
   - 등록: MLW/PGI `rh_ic` 또는 `rh_no_ic` 응답 / MRCG `rhd_ppc_adm` 아무거나 1
   - f/u: MLW/PGI `rhf_disch_dt` 또는 `rhf_disch_dt_na` / MRCG `fwu_dof` 또는 `fwu_tof_up`
6. 요약표: `n_total`(전체 HOS 고유 record), `n_enrolled_rhd`, `n_followup`, `pct_followup`,
   `rh_ic`/`rh_no_ic` 응답별 개수(고유 record 기준)
7. RHD 변수 사이트별 비교
   - 7.1 설정: `var_prefix <- "^rh"`, `target_event`, `varmap_file`(PGI, MRCG), `low_threshold <- 90`
   - 7.2 함수: 변수 타입 분류(Cate/Check/Cont/Calc/Date/Time/Text), branching logic → R 변환,
     타입별 요약(`summarise_var`), flextable
   - 7.3 **Harmonise**: varmap 파일로 PGI/MRCG를 MLW 변수명·코딩으로 변환
     (record당 1행: checkbox는 아무 행에서나 체크면 1, 나머지는 첫 non-missing).
     식이 비어 있는데 site_fields만 적힌 행을 경고 목록으로 보여줌.
   - 7.4 분석 행, 7.5 통합 Data Dictionary(사이트 간 차이 `issues`), 7.6 통합 선택지 기준으로 값 채우기
8. RHD 케이스 요약: 사이트별 케이스 수, 등록일 범위(`rh_ic_dt`), 나이대별 수, 사이트별 ID 리스트
   → `SAVAC_HOS_RHD_cases_YYYYMMDD.xlsx`
9. 워드 리포트 `SAVAC_HOS_RHD_report_YYYYMMDD.docx`: 9.1 케이스 요약 표 → 9.2 변수 비교
   (사이트 개요, dictionary 차이, 완성도 개요, 변수별 상세)
10. 엑셀 저장(선택)

### varmap 파일 규칙
열: `ref_field, ref_form, ref_label, ref_type, ref_choices, match, site_expr, row_filter,
site_fields, site_form, site_label, site_choices, note, confirmed`
- RMD는 `site_expr`만 실행한다. 다른 열은 참고용.
- `site_expr`: 사이트 데이터에서 MLW 코딩 값을 만드는 R 식. 체크박스 필드명만 쓰면 옵션 전체 복사.
  헬퍼: `to_date(x)`, `yn12(x)`(1/0 → 1 Yes/2 No), `chk(cond)`(→ 1/0), `lab("field", x)`(코드→라벨)
- `row_filter`: 그 조건을 만족하는 행만 사용 (MRCG follow-up은 `fwu_tof_up %in% 1` = 28일)

### MRCG 매칭에서 정한 것 / 남은 것
- MUAC: MLW mm, MRCG cm → ×10
- `rh_disch_dt`: MRCG `adm_dod_dd`(퇴원일, 사망 시 사망일) → 결과가 사망(`adm_out_dis`=5)이면 NA
- `rh_ic`: 본인 또는 부모 동의 있으면 1, 둘 다 0이면 2 (MRCG에 waiver 없음)
- `rh_eval`: MRCG `cin_eco_rts`는 단일 선택, 중증도 변수 없음
- `rh_med`: Benzathine→IM penicillin, Oral pen V→oral penicillin/Penicillin V, Erythromycin→Macrolide,
  Warfarin→Anti-coagulants, Other cardiac→diuretics/anti-hypertensives/other (Approximate)
- 진단(`rh_dgn_*`) ← `rhd_dcy_rhd` 1~4
- **미정: `rh_arfhist`** (MLW는 Yes를 출처별 1~3으로 나눔, MRCG `phr_arf`는 Yes/No) → `site_expr` 비워 둠
- 사용자가 varmap을 한 번 고쳤다가 "처음 버전이 맞다"고 해서 처음 버전 유지 중

### 나이
- 나이대: `<5`, `5-14`, `15-18`, `19+`, `Missing` (만 나이 = floor, 15세는 15-18)
- "어린이/young child" 기준은 프로토콜 확인 필요 (임상적으로 young child는 보통 <5세,
  RHD 연구의 children은 보통 5-14세). 한때 "요약은 14세 이하만"이라고 했다가 **취소함** → 현재 전체 나이.

```{r load-functions}
# Read records from one project ("raw" or "label")
read_redcap <- function(token, site, raw_or_label = "raw") {
  message("> ", site, " [", raw_or_label, "] loading...")
  res <- REDCapR::redcap_read(
    redcap_uri   = uri,
    token        = token,
    raw_or_label = raw_or_label,
    batch_size   = 500,
    verbose      = FALSE
  )
  if (!res$success) {
    warning(site, " [", raw_or_label, "] failed: ", res$outcome_message)
    return(NULL)
  }
  message("  OK: ", nrow(res$data), " rows / ", ncol(res$data), " cols")
  res$data
}

# Read data dictionary from one project
read_metadata <- function(token, site) {
  message("> ", site, " [metadata] loading...")
  res <- REDCapR::redcap_metadata_read(redcap_uri = uri, token = token, verbose = FALSE)
  if (!res$success) {
    warning(site, " [metadata] failed: ", res$outcome_message)
    return(NULL)
  }
  res$data
}
```

# 7. RHD variables - summary by site

Target records = RHD enrolled records (same definition as `n_enrolled_rhd`),
using rows of the RHD event (`rhd_arm_1`).
All variables matching `var_prefix` (default: starting with `rh`, i.e. `rh_`,

1. Combined data dictionary - union of selected variables and choices across sites
2. Site values filled in by the combined dictionary
3. Completeness overview - one row per variable, answered / denominator per site
4. Detail tables - one comparison table per variable

```{r trig-functions}
strip_html <- function(x) trimws(gsub("<.*?>", "", x))

# Data dictionary of selected variables with variable type
classify_fields <- function(m) {
  m %>%
    filter(grepl(var_prefix, field_name),
           field_type != "descriptive",
           !grepl(exclude_pattern, field_name)) %>%
    mutate(
      field_label = strip_html(field_label),
      validation  = coalesce(text_validation_type_or_show_slider_number, ""),
      var_type = case_when(
        field_type %in% c("radio", "dropdown", "yesno", "truefalse")  ~ "Cate",
        field_type == "checkbox"                                      ~ "Check",
        field_type == "calc"                                          ~ "Calc",
        field_type == "slider"                                        ~ "Cont",
        field_type == "text" & grepl("^date", validation)             ~ "Date",
        field_type == "text" & grepl("^time", validation)             ~ "Time",
        field_type == "text" & grepl("^(number|integer)", validation) ~ "Cont",
        TRUE                                                          ~ "Text"
      ),
      choices = case_when(
        field_type == "yesno"     ~ "1, Yes | 0, No",
        field_type == "truefalse" ~ "1, True | 0, False",
        TRUE                      ~ select_choices_or_calculations
      )
    )
}

# "1, Yes | 0, No" -> code / label table
parse_choices <- function(s) {
  if (is.na(s) || s == "") return(tibble(code = character(), label = character()))
  parts <- trimws(strsplit(s, "\\|")[[1]])
  tibble(code  = trimws(sub(",.*$", "", parts)),
         label = strip_html(sub("^[^,]*,", "", parts)))
}

# REDCap branching logic -> R expression
logic_to_r <- function(x) {
  if (is.na(x) || trimws(x) == "") return(NA_character_)
  x <- gsub("\n", " ", x)
  x <- gsub("\\[event-name\\]", "[redcap_event_name]", x)
  x <- gsub("\\[[^]]*_arm_[^]]*\\]", "", x)                            # drop [event_arm_1] prefix
  x <- gsub("\\]\\[current-instance\\]", "]", x)
  x <- gsub("\\[(\\w+)\\(([A-Za-z0-9_]+)\\)\\]", "[\\1___\\2]", x)     # checkbox [var(1)]
  x <- gsub("\\[(\\w+)\\]\\s*<>\\s*(''|\"\")", "!is.na(\\1)", x)
  x <- gsub("\\[(\\w+)\\]\\s*=\\s*(''|\"\")", "is.na(\\1)", x)
  x <- gsub("\\[(\\w+)\\]", "\\1", x)
  x <- gsub("<>", "!=", x)
  x <- gsub("(?<![<>!=])=(?!=)", "==", x, perl = TRUE)
  x <- gsub("\\band\\b", "&", x, ignore.case = TRUE)
  x <- gsub("\\bor\\b", "|", x, ignore.case = TRUE)
  x
}

# Keep rows meeting branching logic; if logic cannot be evaluated, keep all rows
apply_logic <- function(dat, logic) {
  cond <- logic_to_r(logic)
  if (is.na(cond)) return(list(dat = dat, applied = NA))
  keep <- tryCatch(eval(parse(text = cond), envir = dat), error = function(e) NULL)
  if (!is.null(keep) && length(keep) == 1) keep <- rep(keep, nrow(dat))
  if (is.null(keep) || length(keep) != nrow(dat)) return(list(dat = dat, applied = FALSE))
  list(dat = dat[keep %in% TRUE, , drop = FALSE], applied = TRUE)
}

# Rows of target records (in the given event) where any selected variable has a response
get_form_rows <- function(df, dict, ids, event = NA) {
  df <- df %>% filter(record_id %in% ids)
  if (!is.na(event)) df <- df %>% filter(redcap_event_name == event)
  check_fields <- dict$field_name[dict$var_type == "Check"]
  other_fields <- dict$field_name[!dict$var_type %in% c("Check", "Calc")]
  cols <- names(df)[names(df) %in% other_fields |
                    sub("___.*$", "", names(df)) %in% check_fields]
  if (length(cols) == 0 || nrow(df) == 0) return(df[0, ])
  answered <- Reduce(`|`, lapply(cols, function(cl) {
    if (grepl("___", cl)) df[[cl]] %in% c(1, "1")
    else !is.na(df[[cl]]) & trimws(as.character(df[[cl]])) != ""
  }))
  df[answered, , drop = FALSE]
}

fmt_n_pct <- function(k, d) {
  if (d == 0) return(as.character(k))
  sprintf("%d (%.1f%%)", as.integer(k), k / d * 100)
}
fmt_num <- function(v, digits = 1) formatC(v, format = "f", digits = digits)

# Summary of one variable for one site
# d:  this site's dictionary row; mc: master choices of the field (code, label, ord)
# tab: rows (row, value, ord); ord 900 = Missing / None checked, 999 = Total
# k: number answered, n: denominator after branching logic
# Choices not offered at this site are shown as "-"
summarise_var <- function(dat, d, mc) {
  lg  <- apply_logic(dat, d$branching_logic)
  dat <- lg$dat
  n   <- nrow(dat)
  f   <- d$field_name
  site_codes <- parse_choices(d$choices)$code

  if (d$var_type != "Check" && !f %in% names(dat)) {
    tab <- tibble(row = "Not exported", value = "-", ord = 1)
    k   <- NA_integer_
  } else if (d$var_type == "Cate") {
    x   <- as.character(dat[[f]])
    cnt <- vapply(mc$code, function(cd) sum(x %in% cd), integer(1))
    val <- ifelse(mc$code %in% site_codes, fmt_n_pct(cnt, n), "-")
    # Values not in the dictionary, shown as raw code
    unk     <- setdiff(unique(na.omit(x)), mc$code)
    unk_lab <- if (length(unk) > 0) paste0("[code ", unk, "]") else character(0)
    unk_val <- if (length(unk) > 0) fmt_n_pct(vapply(unk, function(cd) sum(x %in% cd), integer(1)), n) else character(0)
    k   <- sum(!is.na(x))
    tab <- tibble(row   = c(mc$label, unk_lab, "Missing"),
                  value = c(val, unk_val, fmt_n_pct(n - k, n)),
                  ord   = c(mc$ord, 800 + seq_along(unk), 900))
  } else if (d$var_type == "Check") {
    cols <- paste0(f, "___", tolower(gsub("-", "_", mc$code)))
    hit  <- lapply(cols, function(cl) if (cl %in% names(dat)) dat[[cl]] %in% c(1, "1") else NULL)
    has  <- !vapply(hit, is.null, logical(1))
    cnt  <- vapply(hit, function(h) if (is.null(h)) 0L else sum(h), integer(1))
    none <- if (any(has)) sum(Reduce(`+`, hit[has]) == 0) else n
    k    <- n - none
    tab <- tibble(row   = c(mc$label, "None checked"),
                  value = c(ifelse(has, fmt_n_pct(cnt, n), "-"), fmt_n_pct(none, n)),
                  ord   = c(mc$ord, 900))
  } else if (d$var_type %in% c("Cont", "Calc")) {
    v <- suppressWarnings(as.numeric(as.character(dat[[f]])))
    k <- sum(!is.na(v))
    tab <- tibble(
      row   = c("N", "Missing", "Mean (SD)", "Median", "Min, Max"),
      value = c(as.character(k),
                fmt_n_pct(n - k, n),
                if (k > 0) paste0(fmt_num(mean(v, na.rm = TRUE)), " (", fmt_num(sd(v, na.rm = TRUE), 2), ")") else "-",
                if (k > 0) fmt_num(median(v, na.rm = TRUE)) else "-",
                if (k > 0) paste0(fmt_num(min(v, na.rm = TRUE)), ", ", fmt_num(max(v, na.rm = TRUE))) else "-"),
      ord   = c(1, 900, 2, 3, 4)
    )
  } else if (d$var_type %in% c("Date", "Time")) {
    v <- as.character(dat[[f]])
    v <- v[!is.na(v) & v != ""]
    k <- length(v)
    tab <- tibble(row   = c("N", "Missing", "Min", "Max"),
                  value = c(as.character(k), fmt_n_pct(n - k, n),
                            if (k > 0) min(v) else "-", if (k > 0) max(v) else "-"),
                  ord   = c(1, 900, 2, 3))
  } else {
    v <- as.character(dat[[f]])
    answered <- !is.na(v) & trimws(v) != ""
    k <- sum(answered)
    tab <- tibble(row   = c("N", "Missing", "Unique values"),
                  value = c(as.character(k), fmt_n_pct(n - k, n),
                            as.character(length(unique(v[answered])))),
                  ord   = c(1, 900, 2))
  }

  tab <- bind_rows(tab, tibble(row = "Total", value = as.character(n), ord = 999))
  list(tab = tab, applied = lg$applied, k = as.integer(k), n = n)
}
```

## 7.3 Harmonise sites to MLW variables

Sites with a varmap file (PGI, MRCG) are converted to MLW variable names and coding:
each `site_expr` is evaluated on one row per record (checkbox = checked in any
row, other fields = first non-missing value; `row_filter` limits the rows used).
The MLW data dictionary is then used for these sites, so questions, answers and
order are the same as MLW. Unmapped MLW variables show as "Not in form".

```{r harmonise}
# Helpers available in varmap site_expr
to_date <- function(x) as.Date(as.character(x))
yn12    <- function(x) ifelse(x %in% 1, 1, ifelse(x %in% 0, 2, NA))   # yes/no 1/0 -> 1 Yes / 2 No
chk     <- function(cond) as.integer(cond %in% TRUE)                   # condition -> checkbox 1/0

first_value <- function(v) { x <- v[!is.na(v)]; if (length(x) > 0) x[1] else v[NA_integer_] }
max_value   <- function(v) if (all(is.na(v))) NA_real_ else max(suppressWarnings(as.numeric(v)), na.rm = TRUE)

# One row per record: checkbox columns = checked in any row, others = first non-missing value
collapse_record <- function(d) {
  d %>%
    group_by(record_id) %>%
    summarise(across(everything(),
                     ~ if (grepl("___", cur_column())) max_value(.x) else first_value(.x)),
              .groups = "drop")
}

# Convert one site's data to MLW variables using its varmap
harmonise_site <- function(df, site_meta, vm, ids) {
  vm <- vm %>%
    mutate(across(everything(), ~ coalesce(as.character(.x), ""))) %>%
    filter(ref_field != "", site_expr != "")
  df <- df %>% filter(record_id %in% ids)

  # Code -> choice label of a site field (used as lab("field", x) in site_expr)
  lab <- function(field, x) {
    ch <- parse_choices(site_meta$select_choices_or_calculations[site_meta$field_name == field][1])
    ch$label[match(as.character(x), ch$code)]
  }
  env <- environment()

  # Site columns used by expressions and filters
  toks <- unique(unlist(regmatches(c(vm$site_expr, vm$row_filter),
                                   gregexpr("[A-Za-z][A-Za-z0-9_]*", c(vm$site_expr, vm$row_filter)))))
  used <- names(df)[names(df) %in% toks | sub("___.*$", "", names(df)) %in% toks]
  cols <- unique(c("record_id", used))
  rec  <- collapse_record(df[, cols, drop = FALSE])

  out <- tibble(record_id = rec$record_id)
  log <- vector("list", nrow(vm))
  for (i in seq_len(nrow(vm))) {
    ref  <- vm$ref_field[i]
    expr <- vm$site_expr[i]
    filt <- vm$row_filter[i]

    dat <- rec
    if (filt != "") {
      keep <- tryCatch(eval(parse(text = filt), envir = df, enclos = env), error = function(e) NULL)
      dat  <- if (is.null(keep)) rec[0, ] else collapse_record(df[keep %in% TRUE, cols, drop = FALSE])
    }
    m <- match(out$record_id, dat$record_id)

    cb_cols <- if (grepl("^[A-Za-z0-9_]+$", expr)) grep(paste0("^", expr, "___"), names(dat), value = TRUE) else character(0)
    if (!grepl("___", ref) && length(cb_cols) > 0) {
      # Bare checkbox field: copy all options with the same codes
      for (cl in cb_cols) out[[sub(paste0("^", expr), ref, cl)]] <- dat[[cl]][m]
      status <- "ok"
    } else {
      val <- tryCatch(eval(parse(text = expr), envir = dat, enclos = env), error = function(e) e)
      if (inherits(val, "error")) {
        status <- conditionMessage(val)
      } else {
        if (length(val) == 1) val <- rep(val, nrow(dat))
        out[[ref]] <- val[m]
        status <- "ok"
      }
    }
    log[[i]] <- tibble(ref_field = ref, site_expr = expr, status = status)
  }

  out <- out %>% mutate(redcap_event_name = NA_character_, redcap_repeat_instrument = NA_character_)
  list(data = out, log = bind_rows(log))
}
```

```{r cases-build}
  df <- dat_cmp[[s]] %>% filter(record_id %in% target_ids[[s]])
  if (!is.na(event_cmp[[s]])) df <- df %>% filter(redcap_event_name == event_cmp[[s]])
  if ("redcap_repeat_instrument" %in% names(df)) df <- df %>% filter(is.na(redcap_repeat_instrument))

  # Variables missing at a site are added as NA
  for (v in c("rh_ic_dt", "rh_age_year", "rh_age_month", "rh_age_day")) {
    if (!v %in% names(df)) {
      warning(s, ": ", v, " not found")
      df[[v]] <- NA
    }
  }

  df %>%
    transmute(
      record_id = as.character(record_id),
      enrol_dt  = to_date(rh_ic_dt),
      # Age in years; months / days used only when years is missing (under 1 year)
      age_years = coalesce(suppressWarnings(as.numeric(rh_age_year)),
                           suppressWarnings(as.numeric(rh_age_month)) / 12,
                           suppressWarnings(as.numeric(rh_age_day)) / 365.25)
    ) %>%
    # Collapse to one row per record (first non-missing value)

    summarise(enrol_dt  = first_value(enrol_dt),
              age_years = first_value(age_years),

    mutate(
      age_group = cut(floor(age_years), breaks = age_breaks, labels = age_labels, right = FALSE),
      age_group = factor(coalesce(as.character(age_group), "Missing"),
                         levels = c(age_labels, "Missing"))
    )
}
```

```{r functions}
# Build trigger dataset with baseline (bs_) variables and age
# baseline_event / trigger_event: event names differ by site
make_comm_trigger <- function(df,
                              baseline_event = "baseline_arm_1",
                              trigger_event  = "trigger_arm_1") {

  # Baseline: non-repeating row only (one row per record), bs_ variables only
  bs <- df %>%
    filter(redcap_event_name == baseline_event,
           is.na(redcap_repeat_instrument)) %>%
    select(record_id, starts_with("bs_"))

  # Add age-related variables missing in some sites (filled with NA)
  for (v in c("bs_dob", "bs_ic_dt", "bs_age_year", "bs_age_month", "bs_age_calc")) {
    if (!v %in% names(bs)) bs[[v]] <- NA
  }

  # DOB usable: if bs_dob_known exists (MRCG), only when bs_dob_known == 1
  bs$dob_ok <- if ("bs_dob_known" %in% names(bs)) bs$bs_dob_known %in% 1 else TRUE

  bs <- bs %>%
    mutate(
      # as.character() first so all-NA logical columns convert safely
      bs_dob   = as.Date(as.character(bs_dob)),
      bs_ic_dt = as.Date(as.character(bs_ic_dt)),

      # Age at informed consent from DOB
      age_dob = if_else(dob_ok,
                        time_length(interval(bs_dob, bs_ic_dt), "year"),
                        NA_real_),

      # REDCap-calculated age
      age_calc = as.numeric(bs_age_calc),

      # Reported age (years + months)
      age_reported = if_else(
        is.na(bs_age_year),
        NA_real_,
        as.numeric(bs_age_year) + coalesce(as.numeric(bs_age_month), 0) / 12
      ),

      # Final age: DOB first, then REDCap-calculated age, then reported
      age_exact  = coalesce(age_dob, age_calc, age_reported),
      age_years  = round(age_exact, 1),
      age_source = case_when(
        !is.na(age_dob)      ~ "dob",
        !is.na(age_calc)     ~ "calc",
        !is.na(age_reported) ~ "reported",
        TRUE                 ~ NA_character_
      )
    ) %>%
    select(-dob_ok)

  # Trigger: drop empty bs_ columns, then attach baseline info
  df %>%
    filter(redcap_event_name == trigger_event) %>%
    select(-starts_with("bs_")) %>%
    select(where(~ !all(is.na(.x)))) %>%          # drop columns empty in trigger rows
    mutate(record_id = as.character(record_id)) %>%
    left_join(bs %>% mutate(record_id = as.character(record_id)),
              by = "record_id", relationship = "many-to-one")
}

# Age group: completed years (floor) from unrounded age, so 18.9 stays in 15-18
add_age_group <- function(df) {
  df %>%
    mutate(
      age_int   = floor(age_exact),
      age_group = case_when(
        age_int <  5                 ~ "<5",
        age_int >= 5  & age_int < 15 ~ "5-14",

        TRUE                         ~ "Missing"
      ),
      age_group = factor(age_group, levels = c("<5", "5-14", "15-18", "19+", "Missing"))
    )
}
```

```{r cmp-functions}
strip_html <- function(x) trimws(gsub("<.*?>", "", x))

# Data dictionary of selected variables with variable type
classify_fields <- function(m) {
  m %>%
    filter(grepl(var_prefix, field_name),
           field_type != "descriptive",
           !grepl(exclude_pattern, field_name)) %>%
    mutate(
      field_label = strip_html(field_label),
      validation  = coalesce(text_validation_type_or_show_slider_number, ""),
      var_type = case_when(
        field_type %in% c("radio", "dropdown", "yesno", "truefalse")  ~ "Cate",
        field_type == "checkbox"                                      ~ "Check",
        field_type == "calc"                                          ~ "Calc",
        field_type == "slider"                                        ~ "Cont",
        field_type == "text" & grepl("^date", validation)             ~ "Date",
        field_type == "text" & grepl("^time", validation)             ~ "Time",
        field_type == "text" & grepl("^(number|integer)", validation) ~ "Cont",
        TRUE                                                          ~ "Text"
      ),
      choices = case_when(
        field_type == "yesno"     ~ "1, Yes | 0, No",
        field_type == "truefalse" ~ "1, True | 0, False",
        TRUE                      ~ select_choices_or_calculations
      )
    )
}

# "1, Yes | 0, No" -> code / label table
parse_choices <- function(s) {
  if (is.na(s) || s == "") return(tibble(code = character(), label = character()))
  parts <- trimws(strsplit(s, "\\|")[[1]])
  tibble(code  = trimws(sub(",.*$", "", parts)),
         label = strip_html(sub("^[^,]*,", "", parts)))
}

# REDCap branching logic -> R expression
logic_to_r <- function(x) {
  if (is.na(x) || trimws(x) == "") return(NA_character_)
  x <- gsub("\n", " ", x)
  x <- gsub("\\[event-name\\]", "[redcap_event_name]", x)
  x <- gsub("\\[[^]]*_arm_[^]]*\\]", "", x)                            # drop [event_arm_1] prefix
  x <- gsub("\\]\\[current-instance\\]", "]", x)
  x <- gsub("\\[(\\w+)\\(([A-Za-z0-9_]+)\\)\\]", "[\\1___\\2]", x)     # checkbox [var(1)]
  x <- gsub("\\[(\\w+)\\]\\s*<>\\s*(''|\"\")", "!is.na(\\1)", x)
  x <- gsub("\\[(\\w+)\\]\\s*=\\s*(''|\"\")", "is.na(\\1)", x)
  x <- gsub("\\[(\\w+)\\]", "\\1", x)
  x <- gsub("<>", "!=", x)
  x <- gsub("(?<![<>!=])=(?!=)", "==", x, perl = TRUE)
  x <- gsub("\\band\\b", "&", x, ignore.case = TRUE)
  x <- gsub("\\bor\\b", "|", x, ignore.case = TRUE)
  x
}

# Keep rows meeting branching logic; if logic cannot be evaluated, keep all rows
apply_logic <- function(dat, logic) {
  cond <- logic_to_r(logic)
  if (is.na(cond)) return(list(dat = dat, applied = NA))
  keep <- tryCatch(eval(parse(text = cond), envir = dat), error = function(e) NULL)
  if (!is.null(keep) && length(keep) == 1) keep <- rep(keep, nrow(dat))
  if (is.null(keep) || length(keep) != nrow(dat)) return(list(dat = dat, applied = FALSE))
  list(dat = dat[keep %in% TRUE, , drop = FALSE], applied = TRUE)
}

# Rows of target records (in the given event) where any selected variable has a response
get_form_rows <- function(df, dict, ids, event = NA) {
  df <- df %>% filter(record_id %in% ids)
  if (!is.na(event)) df <- df %>% filter(redcap_event_name == event)
  check_fields <- dict$field_name[dict$var_type == "Check"]
  other_fields <- dict$field_name[!dict$var_type %in% c("Check", "Calc")]
  cols <- names(df)[names(df) %in% other_fields |
                    sub("___.*$", "", names(df)) %in% check_fields]
  if (length(cols) == 0 || nrow(df) == 0) return(df[0, ])
  answered <- Reduce(`|`, lapply(cols, function(cl) {
    if (grepl("___", cl)) df[[cl]] %in% c(1, "1")
    else !is.na(df[[cl]]) & trimws(as.character(df[[cl]])) != ""
  }))
  df[answered, , drop = FALSE]
}

fmt_n_pct <- function(k, d) {
  if (d == 0) return(as.character(k))
  sprintf("%d (%.1f%%)", as.integer(k), k / d * 100)
}
fmt_num <- function(v, digits = 1) formatC(v, format = "f", digits = digits)

# Summary of one variable for one site
# d:  this site's dictionary row; mc: master choices of the field (code, label, ord)
# tab: rows (row, value, ord); ord 900 = Missing / None checked, 999 = Total
# k: number answered, n: denominator after branching logic
# Choices not offered at this site are shown as "-"
summarise_var <- function(dat, d, mc) {
  lg  <- apply_logic(dat, d$branching_logic)
  dat <- lg$dat
  n   <- nrow(dat)
  f   <- d$field_name
  site_codes <- parse_choices(d$choices)$code

  if (d$var_type != "Check" && !f %in% names(dat)) {
    tab <- tibble(row = "Not exported", value = "-", ord = 1)
    k   <- NA_integer_
  } else if (d$var_type == "Cate") {
    x   <- as.character(dat[[f]])
    cnt <- vapply(mc$code, function(cd) sum(x %in% cd), integer(1))
    val <- ifelse(mc$code %in% site_codes, fmt_n_pct(cnt, n), "-")
    # Values not in the dictionary, shown as raw code
    unk     <- setdiff(unique(na.omit(x)), mc$code)
    unk_lab <- if (length(unk) > 0) paste0("[code ", unk, "]") else character(0)
    unk_val <- if (length(unk) > 0) fmt_n_pct(vapply(unk, function(cd) sum(x %in% cd), integer(1)), n) else character(0)
    k   <- sum(!is.na(x))
    tab <- tibble(row   = c(mc$label, unk_lab, "Missing"),
                  value = c(val, unk_val, fmt_n_pct(n - k, n)),
                  ord   = c(mc$ord, 800 + seq_along(unk), 900))
  } else if (d$var_type == "Check") {
    cols <- paste0(f, "___", tolower(gsub("-", "_", mc$code)))
    hit  <- lapply(cols, function(cl) if (cl %in% names(dat)) dat[[cl]] %in% c(1, "1") else NULL)
    has  <- !vapply(hit, is.null, logical(1))
    cnt  <- vapply(hit, function(h) if (is.null(h)) 0L else sum(h), integer(1))
    none <- if (any(has)) sum(Reduce(`+`, hit[has]) == 0) else n
    k    <- n - none
    tab <- tibble(row   = c(mc$label, "None checked"),
                  value = c(ifelse(has, fmt_n_pct(cnt, n), "-"), fmt_n_pct(none, n)),
                  ord   = c(mc$ord, 900))
  } else if (d$var_type %in% c("Cont", "Calc")) {
    v <- suppressWarnings(as.numeric(as.character(dat[[f]])))
    k <- sum(!is.na(v))
    tab <- tibble(
      row   = c("N", "Missing", "Mean (SD)", "Median", "Min, Max"),
      value = c(as.character(k),
                fmt_n_pct(n - k, n),
                if (k > 0) paste0(fmt_num(mean(v, na.rm = TRUE)), " (", fmt_num(sd(v, na.rm = TRUE), 2), ")") else "-",
                if (k > 0) fmt_num(median(v, na.rm = TRUE)) else "-",
                if (k > 0) paste0(fmt_num(min(v, na.rm = TRUE)), ", ", fmt_num(max(v, na.rm = TRUE))) else "-"),
      ord   = c(1, 900, 2, 3, 4)
    )
  } else if (d$var_type %in% c("Date", "Time")) {
    v <- as.character(dat[[f]])
    v <- v[!is.na(v) & v != ""]
    k <- length(v)
    tab <- tibble(row   = c("N", "Missing", "Min", "Max"),
                  value = c(as.character(k), fmt_n_pct(n - k, n),
                            if (k > 0) min(v) else "-", if (k > 0) max(v) else "-"),
                  ord   = c(1, 900, 2, 3))
  } else {
    v <- as.character(dat[[f]])
    answered <- !is.na(v) & trimws(v) != ""
    k <- sum(answered)
    tab <- tibble(row   = c("N", "Missing", "Unique values"),
                  value = c(as.character(k), fmt_n_pct(n - k, n),
                            as.character(length(unique(v[answered])))),
                  ord   = c(1, 900, 2))
  }

  tab <- bind_rows(tab, tibble(row = "Total", value = as.character(n), ord = 999))
  list(tab = tab, applied = lg$applied, k = as.integer(k), n = n)
}
```

```{r word-age}
# Summary flextable: bold Total row with a line above it
make_summary_ft <- function(df, labels = list()) {
  ft <- flextable(df)
  if (length(labels) > 0) ft <- set_header_labels(ft, values = labels)
  tot <- which(df[[1]] == "Total")
  if (length(tot) > 0) {
    ft <- bold(ft, i = tot)
    if (tot > 1) ft <- hline(ft, i = tot - 1, border = fp_border(width = 2))
  }
  ft <- align(ft, j = 2:ncol(df), align = "center", part = "all")
  ft <- fontsize(ft, size = 9, part = "all")
  autofit(ft)
}
```
